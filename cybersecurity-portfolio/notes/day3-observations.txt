
Day 3 - Baseline HTTP Response

Target: OWASP Juice Shop
URL: http://127.0.0.1:3000/

Observation:
An initial request returned 200 OK.
A subsequent request returned 304 Not Modified.

Headers observed:
If-None-Match
If-Modified-Since
ETag
Last-Modified

Interpretation:
The browser sent conditional request headers.
The server returned 304 Not Modified, indicating
that the cached response could be reused.

Security assessment:
This behavior is normal and does not, by itself,
indicate a vulnerability.

Response Header Review - Language Endpoint

Endpoint: GET /rest/languages
Status: HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

Headers observed:
Access-Control-Allow-Origin: *
X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
Feature-Policy: payment 'self'
X-Recruiting: /#/jobs
ETag: present
Vary: Accept-Encoding

Interpretation:
The response allows cross-origin browser access under
the applicable CORS rules. The nosniff and SAMEORIGIN
headers provide browser-side protections. Other headers
provide application or HTTP metadata.

Security assessment:
The wildcard CORS value is worth reviewing in context,
but this response contains no evidence by itself that
sensitive information is exposed or that a security
boundary is bypassed. No confirmed vulnerability has
been established.
